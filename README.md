https://github.com/qarmin/czkawka


Plataforma de tradução do programa Comparador de Arquivos Duplicados Czkawka/Krokiet

https://crowdin.com/project/czkawka


Para utilizar o arquivo "com.github.qarmin.czkawka.desktop" ou "io.github.qarmin.krokiet.desktop", inicie o Emulador de Terminal na pasta onde está o arquivo que foi baixado.

Utilize o comando abaixo para copiar o arquivo com a extensão ".desktop" para a pasta "/usr/share/applications" e pressione a tecla "Enter".

$ sudo cp com.github.qarmin.czkawka.desktop /usr/share/applications

$ sudo cp io.github.qarmin.krokiet.desktop /usr/share/applications


Utilize o comando abaixo para escrever globalmente todas as entradas dos menus do antiX e pressione a tecla "Enter".

$ sudo desktop-menu --write-out-global
